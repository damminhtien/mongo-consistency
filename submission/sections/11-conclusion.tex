\section{Conclusion}

The conclusion answers RQ1 and RQ2 only when their campaign manifests and
analysis artifacts are complete. RQ1 compares the registered configuration
semantics for RYW, MR, MW, and WFR; RQ2 compares the registered topology
conditions. The counts and rates are taken from generated analysis macros, not
copied into the report source.

A precondition miss, unavailable operation, indeterminate mutation, and
harness error are not consistency violations. If a campaign is incomplete or
the analysis state is \texttt{NO\_DATA}, the report states that the evidence is
insufficient to answer the corresponding question. No finite set of histories
establishes a universal guarantee.
