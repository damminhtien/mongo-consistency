\section{Deployment and settings}

The baseline deployment is a three-member MongoDB replica set in Docker Compose. The runner uses Python and PyMongo and reaches the members through a client-only network. A separate sidecar controls replica-network traffic through a narrow HTTP interface. The design keeps the cluster on one host and records the server version, driver version, Python version, Docker Engine version, Compose version, member identities, and observed roles with each trial \cite{mongodb-replication}.

The locked settings are listed in Table~\ref{tab:settings}. C1-C8 form a full three-factor design. The exact values used in a run belong in its trial manifest as well as in this table.

The target versions are MongoDB 8.0.32, PyMongo 4.18.1, Python 3.14.7, Docker Engine 29.7.2, and Docker Compose 5.5.0. The setup record also stores the resolved image digest. Operation timeout is 5 seconds; election and topology convergence have a separate 30-second barrier.
