\subsection{System and deployment}

The selected database is MongoDB, deployed as a three-member replica set with
one data-bearing primary and two data-bearing secondaries. Docker Compose
provides a client network and a separate replication network. The experiment
runner issues client operations, while a restricted fault controller changes
member availability and replication-path reachability. A topology oracle and
an independent observer verify the roles and final document state recorded in
each history.

\maybefigure[fig:architecture]{submission/figures/architecture.pdf}{Three-member MongoDB deployment with separate client and replication paths.}

The main campaigns used the software versions recorded in the campaign
manifest. The detailed image digest, container ports, network subnets, setup
commands, and runner-isolation evidence are retained in Appendices~\ref{app:configuration}
and~\ref{app:install}.
