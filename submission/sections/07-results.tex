\section{Results}

\subsection{Effect of consistency configuration}

The configuration campaign separates two broad behaviours. Some weak settings
returned completed counterexamples under the adversarial schedules. Stronger
settings often stopped before returning an inconsistent value, leaving an
unavailable or indeterminate history instead.

All \NormalPassCount\ normal controls passed. Figure~\ref{fig:prediction-observation}
shows the adversarial results against the configuration predictions. C1
produced a completed violation in every property trial. C6 produced no
decidable result: its RYW and MR reads were unavailable, while its MW and WFR
histories remained indeterminate. The schedules deliberately created replica
divergence, so these counts are not estimates for ordinary traffic. The full
configuration matrix is in Appendix~\ref{app:full-results}.

Each cell contains five scheduled histories; the denominator excludes unavailable and indeterminate outcomes.}

The RYW and MR schedules show the clearest separation between a completed
regression and an unresolved dependency. Weak or non-causal settings can reach
a lagging member and return an older value; the stronger target setting more
often stops before a stale value is returned. MW is decided from whether the
preceding write identifier is present in the successive write's atomic pre-image.
WFR is decided from the application version present in that pre-image. Histories
without that evidence remain INDETERMINATE; the post-heal witness is used only
for the separate durability analysis.

\subsection{Effect of failures and network partition}

The fault campaign tests whether these configuration effects persist when
the topology changes. It contains \RQTwoHistoryCount\ histories across
\RQTwoFaultEpisodeCount\ shared fault episodes. Of the
\RQTwoDecidableHistoryCount\ decidable histories, \RQTwoViolationCount\
were violations. A further \RQTwoPreconditionMissCount\ histories did not
meet the schedule prerequisite and are not counted as passes or violations.

F1, the secondary loss, and F2, the primary loss, produced no violations among
decidable histories. F2 produced an election and recovery; the protocol resumed
calls after the election barrier, so it does not measure a request issued during
that interval.
F3, the replication-path partition, produced every violation and indeterminate
history. In C6, the majority write often timed out before the dependent
operation could be issued.

The completed F3 counterexamples came from C1 RYW and MW, and from WFR under
C1 and C4. The WFR schedule first wrote version 1 with \texttt{w:1} on the
isolated former primary, outside the subject session. C4's local read returned
that version, but the dependent majority write ran on the elected primary
whose pre-image contained only version 0. The setup write did not use C4's
majority write concern. This WFR result does not contradict the MW prediction
for C4. Under C3 and C6, the required WFR read did not return version 1, so
those histories were precondition misses rather than passes.

\subsection{Mechanism evidence}

The campaign-level patterns can be explained by three controlled contrasts.
The paired histories change causal-session state, read concern, or write
concern while keeping the mechanism comparison explicit. They connect the
returned value or timeout to the route and session metadata recorded in the
history.
