\section{Results}

The analysis state is \texttt{\AnalysisStatus}, and the main campaign manifest is \texttt{\MainCampaignStatus}. It contains \texttt{\HistoryCount} histories: \texttt{\NormalHistoryCount} normal controls and \texttt{\AdversarialHistoryCount} adversarial trials. The separate pilot contains \texttt{\PilotHistoryCount} histories and is not pooled into these results. Tables are generated from \texttt{results/summary/summary.json}; a no-data build shows zero counts rather than copying predicted values.

RQ1 uses the adversarial histories. Of \texttt{\AdversarialHistoryCount} planned adversarial trials, \texttt{\AdversarialUnsupportedCount} did not establish a required topology precondition and are reported as \texttt{UNSUPPORTED}. The violation rate uses only the \texttt{\AdversarialDecidableCount} adversarial histories labelled \texttt{PASS} or \texttt{VIOLATION}. The pilot is excluded. Each cell retains its configuration, property, schedule, and raw-history path.
