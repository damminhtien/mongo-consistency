\section*{AI Usage Statement}
\addcontentsline{toc}{section}{AI Usage Statement}

OpenAI Codex was used to map the report to the project requirements, revise
the LaTeX structure and wording, and check the build and generated report
tables. It did not run the database campaigns or create their raw histories.
The reported measurements and classifications are generated from the saved
histories by the repository's analysis scripts. The project group is
responsible for checking the cited course and database sources, commands,
measurements, explanations, and final PDF against those materials.
