\section*{AI Usage Statement}
\addcontentsline{toc}{section}{AI Usage Statement}

OpenAI Codex assisted with the experiment code, campaign execution through
repository commands, report structure and wording, and validation of the PDF
build. The saved raw histories were produced by the MongoDB runner, not
invented as report text. Reported measurements and classifications are
recomputed from those histories by the repository's analysis scripts. The
project group is responsible for checking the cited course and database
sources, commands, measurements, explanations, and final PDF.
