\section{Method and fault model}

The runner has separate responsibilities: issue a short workload, record the complete history, check the history offline, and aggregate metrics. Keeping the checker independent of the live client makes a saved trace sufficient for replay.

Each operation record contains \texttt{trial\_id}, \texttt{session\_id}, \texttt{operation\_id}, operation type, key, integer version, requested member, actual server address, actual role, read concern, write concern, causal-session state, invocation and response times, status, error details, fault event, and dependency metadata. The history also stores a serialization version and SHA-256 hash.

The logical document is \texttt{x} with an append-only update list. One logical writer allocates integer versions. MW records W1 and W2 on this same document and uses \texttt{parent\_write\_id}. WFR records R1 and a write on the same document with \texttt{depends\_on\_read\_id} and \texttt{depends\_on\_version}. Different-key fixtures are rejected.

The four schedules are property-specific. RYW isolates one secondary replication path, writes on the primary, and reads the same key from that secondary. MR writes a preparation version, reads a fresh secondary, and then reads the isolated secondary in the same session. MW writes W1 before isolating the old primary, waits up to 30 seconds for a new primary, writes W2 on the same key, and takes one observer snapshot. WFR writes and reads on the old side, isolates it, waits for election, writes the dependent W2 on the new primary, and takes one observer snapshot. Normal controls use the same operation shapes without an injected fault.

The operation deadline is 5 seconds. Election and topology convergence have a separate 30-second barrier, and a subtrial has a 60-second deadline. Reads and writes disable retries. The minimum summary contains counts for all six outcome classes, consistency violation rate, operation success, history completion, p50, p95, p99 latency, election time, recovery time, and the factorial contrasts. Consistency violation rate is \texttt{VIOLATION/(PASS+VIOLATION)}. \texttt{UNAVAILABLE} and \texttt{INDETERMINATE} are not placed in that denominator.
