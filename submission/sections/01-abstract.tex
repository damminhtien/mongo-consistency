\section{Abstract}

The project evaluates read-your-writes (RYW), monotonic reads (MR), monotonic writes (MW), and writes-follow-reads (WFR) in a three-member MongoDB replica set. The planned comparison varies read concern, write concern, causal sessions, and fault condition. Each operation is recorded with a logical version, client sequence, dependency metadata, member identity, response status, and latency fields. An offline checker assigns \texttt{PASS}, \texttt{VIOLATION}, or \texttt{UNAVAILABLE} to each target history.

No MongoDB trial is recorded in the current checkout. The report therefore records the method, predictions, checker contract, and reproduction path while measured counts, latency, recovery time, traces, and figures remain \texttt{NOT COLLECTED}. Claims about observed behaviour will be limited to the versions, settings, workloads, and fault schedules that are actually recorded.
