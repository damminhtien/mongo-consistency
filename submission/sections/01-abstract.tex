\section{Abstract}

This study evaluates read-your-writes (RYW), monotonic reads (MR), monotonic
writes (MW), and writes-follow-reads (WFR) in a three-member MongoDB replica
set. It varies read concern, write concern, and explicit causal sessions across
the C1-C8 configuration matrix. Each property has a registered schedule and a
separate offline checker.

The report uses the campaign and analysis state recorded at build time:
\texttt{\MainCampaignStatus} and \texttt{\AnalysisStatus}. It reports the
available history counts and keeps PASS, VIOLATION, UNAVAILABLE,
INDETERMINATE, PRECONDITION\_MISS, and HARNESS\_ERROR distinct. If the analysis
state is \texttt{NO\_DATA}, the build contains no measured campaign conclusion.
Claims apply only to the recorded software versions, settings, topology,
workloads, and schedules.
