\section{Limits}

The baseline uses three containers on one laptop. The containers are logical
replicas, not independent machines. Docker network faults are synthetic and do
not reproduce a real wide-area network. Scheduler, replication, routing, and
election timing can vary between trials.

The workloads are short and synthetic so a checker can evaluate a complete
history. They cover only the registered operations and dependency patterns.
Thirty repetitions are repetitions of these schedules, not a universal
probability estimate. A precondition miss indicates that the required state
was not created; it is reported separately and never converted into a database
failure or violation.

Conclusions apply only to the server and driver versions, image digest,
topology, settings, workloads, and fault schedules recorded in the campaign.
Internal mechanisms are discussed only when supported by observable traces.
