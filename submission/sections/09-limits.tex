\section{Limits}

The baseline uses three containers on one laptop. The containers are logical replicas, not independent machines. Docker network faults are synthetic and do not reproduce a real wide-area network. Scheduler timing, replication timing, driver selection, and election timing can vary between trials.

The workloads are short and synthetic so that a checker can expose a causal counterexample. That design limits the range of application behaviour represented by the measurements. Finite repetitions cannot establish a universal guarantee. Conclusions apply only to the MongoDB server, PyMongo driver, Python runtime, container image, settings, workload, and fault schedule recorded with the histories.

If a partition setup cannot reach a stale member independently of the blocked replication path, that case must be marked unsupported. It must not be presented as a stale-read observation.
