\section{Build and evidence checklist}

The archive includes the following items when they exist in the source tree:

\begin{itemize}
\item the compiled report and its LaTeX source;
\item the bibliography and metadata used for the title page;
\item the course brief, project plan, experimental protocol, and report plan;
\item the slide-page mapping, configuration matrix, prediction manifest, and campaign schedule;
\item setup, experiment, analysis, build, and documentation scripts;
\item source code, tests, raw histories, summaries, figures, and image digests;
\item a package README and a SHA-256 manifest.
\end{itemize}

The package builder excludes version-control metadata, generated output, caches, and virtual environments. Those files are local build state, not project submission material.

The report source uses the official MongoDB and PyMongo references listed below. The archive records the checker version, prediction source revision, raw-history hashes, and the exact outcome classes used by the analysis.
