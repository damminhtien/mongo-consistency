\section{Build and evidence checklist}

The reproduction archive contains source and evidence available at the commit
used for the build:

\begin{itemize}
\item the report PDF and its LaTeX source;
\item bibliography, submission metadata, and package instructions;
\item assignment summary, project plan, protocol, report plan, and slide mapping;
\item configuration matrix, prediction manifest, schedules, and schemas;
\item setup, experiment, analysis, report-build, and validation scripts;
\item source, tests, raw histories, summaries, plots, and image digests when present;
\item a package README and SHA-256 manifest.
\end{itemize}

The package builder excludes version-control metadata, local caches, virtual
environments, and smoke histories. Missing campaign evidence remains missing;
it is not replaced with predicted values.

The report records separate prediction, protocol, and runner provenance. Every
reported outcome is derived by the offline checker from a canonical raw
history.
