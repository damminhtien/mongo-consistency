\section{Build and evidence checklist}

The archive includes the following items when they exist in the source tree:

\begin{itemize}
\item the compiled report and its LaTeX source;
\item the bibliography and metadata used for the title page;
\item the course brief, project plan, experimental protocol, and report plan;
\item setup, experiment, analysis, build, and documentation scripts;
\item source code, tests, raw histories, summaries, and figures;
\item a package README and a SHA-256 manifest.
\end{itemize}

The package builder excludes \texttt{.git/}, \texttt{.codex/}, \texttt{AGENTS}, \texttt{AGENTS.md}, generated output, caches, and virtual environments. Those files are local tooling or build state, not project submission material.
