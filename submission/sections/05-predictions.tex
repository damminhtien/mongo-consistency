\subsection{Configuration matrix and predictions}

The eight configurations combine local or majority read concern, \texttt{w:1}
or majority write concern, and causal sessions that are off or on. The
configuration matrix changes these settings while the property schedule,
logical document, and replica-set topology remain fixed.

\midrule

C3 combines a majority read with a causal session, so the read and the
dependent operation carry a lower bound through the session even though the
write uses \texttt{w:1}. C4 gives the write a majority acknowledgement while
keeping the read local, which makes it useful for the monotonic-write
schedule. C6 combines majority read, majority write, and a causal session; it
is the strongest setting in the matrix for the four tested dependencies.

The matrix gives the settings; the expectations explain what observations would
contradict them. A target prediction is falsified only by a completed,
decidable counterexample. An unavailable or indeterminate trial does not
provide that comparison. C7 is deliberately descriptive for RYW: a completed
stale read there is an observation of the setting, not a failed protected
prediction.

\subsection{Fault expectations}

The configuration campaign changes consistency settings while the schedule
creates controlled replica divergence. The fault campaign asks whether the
same behaviour persists when the topology itself changes.

\begin{description}
\item[F1, secondary loss] Removing one secondary should reduce redundancy
without forcing an election. Operations that remain routable should not create
a new consistency anomaly in the tested schedule.
\item[F2, primary loss] Stopping the primary should produce an election
interval and possible temporary unavailability. The scheduled calls after
recovery should not form a completed invalid history; the election interval is
not directly probed by a subject call.
\item[F3, replication partition] Isolating the former primary from the
majority side should separate a weak acknowledged write from a majority
acknowledgement. A weak setting may return a stale or reordered value, while a
stronger setting may wait or leave the dependent operation unresolved.
\end{description}
