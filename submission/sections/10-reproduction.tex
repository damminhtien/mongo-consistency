\section{Reproduction}

The source tree reserves the following paths:

\begin{verbatim}
configs/            settings, workloads, repetitions, fault schedules
results/raw/        operation histories and trial manifests
results/summary/    derived tables and metrics
figures/            plots generated from raw histories
schemas/            versioned record contracts
scripts/            setup, teardown, fault, build, and check commands
src/                runner, recorder, checker, and analysis code
tests/              offline and harness tests
submission/         LaTeX source, bibliography, and metadata
\end{verbatim}

The target interface is:

\begin{verbatim}
make setup
make pilot
make experiment
make experiment-parallel
make analyse
make submission
make check-schemas
\end{verbatim}

\texttt{make setup} verifies the pinned versions, starts the three-member replica set, builds the restricted runner, and checks stable topology. The pilot runs five adversarial repetitions and one normal smoke trial per configuration/property cell. The main experiment runs 320 normal histories and 960 adversarial histories. \texttt{make experiment-parallel} assigns the same global plan to isolated Compose replica sets and validates the merge before publishing canonical histories; its worker count is recorded in the campaign manifest. \texttt{make analyse} reads canonical raw histories without MongoDB and rebuilds summaries and figures. \texttt{make submission} compiles the PDF, checks source and package documents, and writes the reproduction archive.
