\section{Reproducibility}

The repository contains the Compose deployment, runtime code, configuration
matrix, schedules, schemas, raw histories, and offline checks used to produce
the report. The submitted archive contains the compiled PDF and the code
needed to run the MongoDB campaigns; the authored LaTeX source, tests, raw
histories, and report-building scripts remain outside that archive.

The main commands are:

\begin{verbatim}
make setup
make smoke
make pilot
make experiment
make rq2
make rq3
\end{verbatim}

Appendix~\ref{app:install} gives the installation sequence and the offline
validation commands. Appendix~\ref{app:full-results} gives the full matrices,
audit identities, and additional figures. The report is compiled from the
hand-authored source in \texttt{submission/}; the build may add numeric macros
derived from saved results, but it does not write report prose or sections.
