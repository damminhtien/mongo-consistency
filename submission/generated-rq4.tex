\subsection{Completion and latency}

The completion and latency summary is computed offline from the recorded
configuration and fault histories. It adds no database run or new workload.
For each cell, definitive completion is
\(D=(\mathrm{PASS}+\mathrm{VIOLATION})/\mathrm{attempted}\), where attempted
includes PASS, VIOLATION, UNAVAILABLE, and INDETERMINATE. It is an observed
workload measure, not formal CAP availability.

All-attempt latency includes valid timeout outcomes. Resolved latency uses only
histories with PASS or VIOLATION, so the two samples answer different questions.
The small cells are reported with p50 and p95 values.
